<objective>
Promote genre from a per-request query parameter to session state alongside region and providers (D-03), and lock all three the moment the deck is pinned (D-02).

Purpose: "unanimous match" is only meaningful if every participant votes on one movie list resolved from one set of filters. Genre is the last filter still supplied per client, which is the one remaining way two members of the same session could be handed different decks. Locking at pin time closes the window Phase 3 explicitly deferred to this phase — after pinning there is no configuration left to change.

Output: `genre` on the create-session and replace-filters contracts, genre validation moved to the endpoints that set it, a `DeckController` that reads all three filters from the session row, a 409 on post-pin filter replacement, and test coverage for both halves.
</objective>

<assumption_delta_decision>
The assumption-delta probe's `chosen` family applies squarely to this plan: genre was a value each client chose per request; it becomes a value the session holds.

- **Primary noun:** the *session's filter set* — region, providers and genre together.
- **Decision:** `promote`. Session-level genre becomes the sole source of truth and the per-request genre parameter is removed outright, rather than kept alongside as a fallback. Keeping both would leave a path by which one participant's request could still resolve a different deck than another's, which is the exact divergence D-03 exists to close.
- **Invariant test (accepted, Task 1):** the deck a session serves is derived only from session state, asserted by a request that supplies a genre query parameter and receives a deck identical to one requested without it.
</assumption_delta_decision>
