<objective>
Replace the legacy Thymeleaf prototype with a React SPA served from the same Spring Boot JAR, and
prove the whole stack end-to-end on one thin path: cold-load `/s/{joinCode}` in a browser, enter a
display name, and land on an authenticated screen whose content came from a real REST call carrying
a real bearer token.

This is the phase's tracer. It touches every layer Phase 6 will modify — Gradle build integration,
static-resource serving, backend read surface, HTTP client, router, screen — on exactly one path.
Every later plan expands horizontally out of the slice this plan proves.

Purpose: an architectural dead-end in the single-JAR build integration (D-01) or the SPA deep-link
forwarding would invalidate all four remaining plans. Finding that out after one commit is cheap;
finding it out after the swipe deck, waiting screen and results screen are built is not.

Output: a `./gradlew build` that produces one deployable JAR containing both the API and the SPA,
zero Thymeleaf, and a working join flow.

Two of this plan's four tasks are zero-code human gates (a reversibility gate on D-01/D-02, and a
package-legitimacy gate on the npm dependency set) — the code surface is two tasks.
</objective>
